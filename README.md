# w记账 · 手机记账

给倒手生意用的轻量账本。记下成本和卖价，自动算清每一单的利润；先记库存、卖出再结算；按月看总收入、成本和赚头。现在还有本地小助手 **奶娃**，能看账、算利润、把一句话变成填好的单子。

- **手机优先**：专为 390px 左右的手机屏幕设计，也适配桌面浏览器。
- **奶娃助手**：查本月利润、在售库存、最赚一单，或说“记一单 成本1000 卖1500”，自动帮你填单。
- **自动算利润**：利润 = 卖出收入 − 拿货成本 − 其他费用。
- **备注图片**：一单最多加 6 张收据、聊天记录或实物图；压缩后存在本机，刷新和离线都在，JSON 备份会一起打包。
- **在售库存**：只记成本先入库，卖出时补收入，自动结算。
- **月度统计**：每周净赚、品类收入、最高单笔、成交件数。
- **数据本地**：不上传云端，不需要账号，所有记录存在当前浏览器。
- **可装到桌面**：通过 HTTPS 打开后可添加到主屏幕，并离线使用。
- **可备份迁移**：导出 JSON 完整备份 / CSV 表格，换手机时导入。

## 本地启动（长期、数据只在自己的局域网）

1. 双击 **`启动手机版.bat`**。
2. 电脑会自动打开 `http://127.0.0.1:4173`。
3. 让手机连接同一个 Wi-Fi，打开脚本显示的局域网地址，例如 `http://192.168.1.23:4173`。
4. 如果手机打不开：
   - 第一次运行时，Windows 可能弹出防火墙提示，选择允许；
   - 确认电脑和手机在同一 Wi-Fi，且没有开启 AP 隔离；
   - 公司/公共网络经常禁止设备互访，这时请改用上面的 GitHub Pages 地址。

本地启动需要电脑上有 Python 3。命令行等价于：

```powershell
python -m http.server 4173 --bind 0.0.0.0
```

> 局域网 HTTP 不是安全上下文，浏览器可能不提供完整的 PWA 安装和离线缓存，但正常记账和数据保存不受影响。要完整体验「安装到桌面 + 离线」，请使用上面的 GitHub Pages 地址，或部署到你自己的 HTTPS 静态空间。

## 怎么记账

### 已经卖掉了
底部点 **＋** →「已卖出」→ 填「拿货成本」和「卖出收入」→ 保存。  
底部会实时显示这单净赚多少。

分类可选：**球鞋、数码、美妆、得物搬砖、其他**。旧账目里的「票务」「潮玩」会保留原标签，但新单不再出现这两个选项。

### 先收货，还没卖
点首页「先入库」→ 只填成本 → 存入在售。  
卖出时在首页库存卡上点「卖出」→ 补上卖出收入 → 确认卖出。

### 费用
平台费、快递费、停车费等填在「其他费用」，会从利润里扣掉。

### 备注图片
备注下面可以添加图片（收据、聊天记录、实物图等），一单最多 6 张。图片会自动压缩后保存在本机 IndexedDB，刷新、重开和离线都还在；点缩略图可放大查看，点右上角 × 可移除。

图片不会上传到服务器；导出的 JSON 备份会包含图片，换手机导入后会一起恢复。清理浏览器数据前一定先备份。

### 统计规则
- **只统计已卖出**的账目。
- 月底结算时按「卖出日期」计入当月。
- 在售库存只显示占用成本，不计入利润。
- 毛利率 = 净赚 ÷ 卖出收入。

## 奶娃助手

右下角的黄色小头像就是奶娃，点开就能直接问；装到桌面后，长按图标还可以直接选「问奶娃」。

奶娃头像右上角有个 ×，点一下就能收起；收起后可以在「我的 → 小助手 → 奶娃助手」重新显示。聊天面板右上角的 × 只关闭当前对话，不会收走奶娃入口。

- “本月赚了多少”“上个月亏了多少”
- “在售库存”“最赚的一单”
- “利润怎么算”“怎么备份”
- “记一单 雅诗兰黛小棕瓶 成本400 卖520 费用10”
- “记一单 得物 AJ1 成本800 卖1100”
- “记库存 iPhone 17 Pro 成本7600”

奶娃是**本地运行的规则型助手**，不是联网大模型：所有回答都由本机账目实时计算，不会把账目发给任何 AI 服务，所以离线也能用。它能处理常见的记账问题和简单指令；太开放的闲聊还接不住，需要真 AI 对话的话，可以再接云端 API。

## 数据安全与备份

- 账目和备注图片保存在当前浏览器（账目在 localStorage，图片在 IndexedDB），不上传服务器。
- 换手机、换浏览器、清理浏览器数据前，先在「我的」导出 **JSON 备份**；备份会包含备注图片。
- 导入备份会**替换**当前账目，并恢复备份里的图片；导入前会再次确认。
- CSV 可以直接用 Excel / 微信表格打开。
- 数据按网址隔离：以后换到别的网址，原数据不会自动带过去，请用 JSON 导出/导入迁移。

## 部署到自己的 HTTPS 空间（推荐长期使用）

这是纯静态应用，不需要后端、数据库或构建步骤。把整个目录上传到任意支持 HTTPS 的静态托管即可：

- Cloudflare Pages
- Netlify（可直接拖拽文件夹）
- Vercel
- GitHub Pages
- 自己的 Nginx / 宝塔站点

注意：
- 必须保留相对路径，不要把 `app.js`、`icons/` 改到别的目录。
- 一定要用 **HTTPS**，否则 Service Worker / PWA 安装 / 离线缓存无法生效。
- `manifest.webmanifest` 的 `start_url` 是 `./`，放在子目录也能用。
